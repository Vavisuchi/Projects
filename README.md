#  Data Science, Analytics & Engineering Portfolio

Welcome to my portfolio! This repository serves as a centralized hub for end-to-end data engineering pipelines, statistical analysis models, interactive visualizations, and domain-specific analytical frameworks across Healthcare, Public Safety, Fintech, Retail, and Consumer Tech.

## Featured Projects Index

###  Healthcare & Public Health Analytics

1. **[WA DOH Food Safety Risk & Resource Allocation Audit](./wa-doh-food-safety)**
   * **Tech Stack:** `Python`, `Pandas`, `NumPy`, `Scoring Engines`
   * **Overview:** Automated data pipeline evaluating operational capacity and backlog stress across 37 Washington State Local Health Jurisdictions (LHJs). Implements a 3-part composite risk model (0–100 scale) to dynamically trigger state inspector deployments and emergency funding.
   * **Key Artifact:** [`wa-doh-food-safety/README.md`](./wa-doh-food-safety)

2. **[Medicare Interactive Episode-of-Care Data Pipeline](./Medicare_Interactive_Data_Pipeline)**
   * **Tech Stack:** `Python`, `Pandas`, `Plotly`, `IPyWidgets`, `Scrollytelling`
   * **Overview:** Interactive scrollytelling analysis evaluating how hospital episode-of-care spending diverges from state and national benchmarks across distinct care phases (pre-admission, index admission, post-discharge).
   * **Key Artifact:** [`Medicare_Interactive_Data_Pipeline/README.md`](./Medicare_Interactive_Data_Pipeline)

3. **[Medicaid Claim Analysis & Hospital Spending](./Medicaid_Claim_Analysis_Healthcare)**
   * **Tech Stack:** `Python`, `Pandas`, `Data Cleaning`, `Financial Aggregation`
   * **Overview:** Quantitative evaluation of Medicare/Medicaid claims to isolate top cost drivers by claim category, profile high-spending hospital facilities, and engineer financial variance metrics relative to national averages.
   * **Key Artifact:** [`Medicaid_Claim_Analysis_Healthcare/README.md`](./Medicaid_Claim_Analysis_Healthcare)
